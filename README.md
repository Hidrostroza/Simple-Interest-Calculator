# Simple Interest Calculator

A small Python program that calculates **simple interest** and the total amount
to be repaid, given a principal, an interest rate, and a time period.

## Description

This project was created as the final project for the IBM *Getting Started with
Git and GitHub* course. It demonstrates a basic Git and GitHub workflow:
creating a repository, adding a README, branching, committing, and opening pull
requests.

The program itself is a simple interest calculator: the user enters the
principal, the annual interest rate, and the time in years, and the program
returns the simple interest and the total amount.

## Formula

```
Simple Interest (SI) = (P × R × T) / 100
Total Amount         = P + SI
```

Where:

- **P** = Principal amount (the initial sum of money)
- **R** = Rate of interest per year (as a percentage)
- **T** = Time period in years

## Usage

Run the program from a terminal:

```bash
python simple_interest.py
```

You will be prompted to enter the principal, rate, and time. The program then
prints the simple interest and the total amount.

## Example

| Input                      | Output                       |
|----------------------------|------------------------------|
| P = 1000, R = 5, T = 2     | Simple Interest = 100.00     |
|                            | Total Amount = 1100.00       |
