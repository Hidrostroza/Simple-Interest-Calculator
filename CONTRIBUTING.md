# Contributing

Thank you for your interest in contributing to the **Simple Interest
Calculator** project! All contributions are accepted and appreciated.

## Types of Contributions

We welcome all kinds of contributions, including:

- **Bug reports** — Report any problem or unexpected behavior you find.
- **Bug fixes** — Fix an existing issue and open a pull request.
- **Documentation improvements** — Improve or clarify the README or other docs.
- **Enhancements** — Add new features or improve existing functionality.
- **Ideas** — Share suggestions and ideas for the project.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and commit them with a clear message.
4. Push your branch and open a pull request describing what you changed.

Thank you for helping improve this project!
